# Support

## Profile and website

For an error in this profile, its links, or the GitHub Pages site, open a
[documentation issue](https://github.com/vartaxe/vartaxe/issues/new/choose).

## Maintained fork

Open endpoint-management maintenance work in:

- [Driver Automation Tool fork](https://github.com/vartaxe/DriverAutomationTool)

The Driver Automation Tool repository is the home for endpoint-management
fork maintenance. Review its upstream attribution, license, and support guidance
before using it.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
