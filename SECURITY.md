# Security policy

## Scope

This repository contains the `vartaxe` GitHub profile and its GitHub Pages site.
It does not contain the deployment scripts described on those pages.

For a vulnerability in an OSD tool, follow that tool's security policy:

- [Add Computer to AD Group](https://github.com/vartaxe/ConfigMgr-OSD-AddComputerToADGroup/security/policy)
- [Copy OSD Logs to File Share](https://github.com/vartaxe/ConfigMgr-OSD-CopyOSDLogToFileShare/security/policy)
- [Disk Partition Layout](https://github.com/vartaxe/ConfigMgr-OSD-DiskPartitionLayout/security/policy)

For a security issue in this profile repository or website, email
[vartaxe@outlook.com](mailto:vartaxe@outlook.com). Do not open a public issue
for a vulnerability or include credentials, private logs, internal URLs, or
other sensitive deployment details.

Only the current `main` branch is supported. Security reports are evaluated
against the repository state and do not constitute live ConfigMgr, Active
Directory, WinPE, SMB, driver, or firmware validation.
